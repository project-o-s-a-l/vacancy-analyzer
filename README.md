# Vacancy Analyzer

Vacancy Analyzer собирает вакансии из открытых источников и подбирает их под профиль кандидата. В карточке видно, какие требования совпали, каких навыков недостаёт и какие условия работодатель не уточнил. Подбор доступен из командной строки и в личном чате Telegram.

## Быстрый старт

Понадобятся Python 3.12 или новее и Docker с Compose для локального PostgreSQL. В свежем клоне скопируйте `.env.example` в `.env`. Создайте и активируйте виртуальное окружение, затем выполните команды из корня репозитория.

```sh
python -m pip install .
docker compose up -d --wait postgres
alembic upgrade head
vacancy-analyzer --help
```

При смене параметров базы обновите `DATABASE_URL` и соответствующие переменные PostgreSQL в `.env`.

## Первый подбор

Для живого сбора установите отдельный пакет адаптеров источников. Каталог нового экземпляра пуст. [Подключение адаптера](docs/COLLECTION.md).

```sh
vacancy-analyzer collect --source trudvsem --pages 1
vacancy-analyzer catalog-status
vacancy-analyzer rank --profile config/profile.example.yaml --top 5
```

Сбор требует доступа к выбранной площадке. Отредактируйте копию примера профиля в `config/profile.local.yaml` и передайте её в `rank`. Возраст публикации, доступность, условия оплаты и обратная связь учитываются отдельно. Команда `skill-gap` покажет, какие навыки чаще встречаются в вакансиях интересующего направления.

Для проверки без сети и без базы можно подготовить учебный каталог.

```sh
vacancy-analyzer evaluation-prepare --output data/demo
vacancy-analyzer evaluation-validate --bundle data/demo
```

## Возможности

- Сбор из HeadHunter, Хабр Карьеры, «Работы России», SuperJob и Авито. Каталог связывает копии одной вакансии и сохраняет историю изменений. [Источники и импорт](docs/COLLECTION.md).
- Профиль, загрузка резюме с подтверждением, рекомендации и обратная связь в Telegram. [Работа с ботом](docs/TELEGRAM.md).
- Правила подбора и журнал объяснений. Дополнительно доступны локальный разбор через Ollama и экспериментальные модели ранжирования. [Устройство проекта](docs/ARCHITECTURE.md).
- Раздельные выборки для обучения и проверки, слепая разметка и сравнение ранжирования. [Проверка качества](docs/BENCHMARK.md).

Для разработки и запуска тестов см. [руководство участника](CONTRIBUTING.md).
