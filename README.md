# Vacancy Analyzer

Собирает вакансии с нескольких площадок, объединяет копии и подбирает их по профилю кандидата. Команды доступны через CLI и Telegram.

Для сбора установите отдельный пакет адаптеров источников с точками входа `vacancy_analyzer.sources`.

## Запуск

В виртуальном окружении с Python 3.12 или новее выполните `python -m pip install -e .`. В свежем клоне скопируйте `.env.example` в `.env`, затем запустите PostgreSQL и примените миграции.

```sh
docker compose up -d --wait postgres
alembic upgrade head
vacancy-analyzer --help
```

Сохраните настройки кандидата в `config/profile.local.yaml` по [примеру](config/profile.example.yaml). После сбора каталога выполните `vacancy-analyzer rank --profile config/profile.local.yaml --top 5`. Для бота укажите `TELEGRAM_BOT_TOKEN` в локальном окружении и выполните `vacancy-analyzer bot`.

Извлечённые сведения о кандидате и вакансии сопровождаются ссылками на фрагменты исходного текста. [Инструкция по оценке](docs/evaluation/REVIEW.md).

Сборщик сохраняет позицию обхода. Фоновый обработчик ставит задания анализа в очередь, повторные запросы используют сохранённые результаты подбора.

Редактор профиля позволяет менять должности, опыт и условия поиска. Подтверждённые показы и отзывы хранятся отдельно от текущей выдачи.
