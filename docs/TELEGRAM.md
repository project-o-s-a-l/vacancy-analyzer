# Работа с ботом

1. Создайте бота через BotFather и укажите токен в `TELEGRAM_BOT_TOKEN` локального файла `.env`.
2. Примените миграции командой `alembic upgrade head` и запустите `vacancy-analyzer bot`.
3. Откройте личный чат, отправьте `/start` и заполните навыки, желаемую должность и условия работы. Команда `/profile` открывает редактор профиля.

Резюме можно прикрепить в диалоге. Бот показывает извлечённые сведения как черновик. Пользователь проверяет данные перед применением.

Команда `/latest` подбирает вакансию. Карточка содержит условия, признаки соответствия, сведения о недостающих навыках и ссылку на площадку. Оценка, сохранение и отметка об отклике учитываются при следующих показах. Команда `/skillgap` строит сводку требований по желаемым должностям.

Входящие команды фиксируются в PostgreSQL. Внутри чата они выполняются в порядке поступления. Если бот перезапустился посреди изменения профиля или отправки ответа, он предложит проверить результат в чате перед повтором команды.

Для просмотра выдачи из CLI используйте `vacancy-analyzer notify --user-id <id> --dry-run` с ID зарегистрированного пользователя.
