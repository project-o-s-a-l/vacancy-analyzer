# Архитектура

Бот и CLI вызывают одни и те же сервисы подбора. PostgreSQL хранит каталог, профили, очередь анализа и журнал показов. Внешние площадки и Telegram изолированы адаптерами.

| Каталог | Ответственность |
| --- | --- |
| `src/collectors` | Контракт источника и подключение установленных адаптеров вакансий |
| `src/domain` | Типы профиля, вакансии, требований и решений подбора |
| `src/storage` | ORM, запросы к каталогу, история и транзакции |
| `src/processing` и `src/nlp` | Чтение резюме, очистка текста, извлечение фактов и подтверждающих фрагментов |
| `src/scoring` | Проверка условий кандидата, поиск соответствий и расчёт баллов |
| `src/jobs` | Сбор, фоновые задачи, рекомендации и команды CLI |
| `src/bot` | Диалоги, редактор профиля, форматирование карточек и доставка |

## Каталог и выдача

Сборщик отделяет дату публикации от даты обнаружения и последней успешной проверки. Для каждой версии исходных данных сохраняется снимок. Поиск сначала учитывает обязательные условия, известную историю пользователя и группы копий. Для выбранных кандидатов вычисляются подробные соответствия и объяснения. Неизвестное требование отражается отдельно.

Перед отправкой сервис повторно сверяет состояние вакансии и профиля. После подтверждённой доставки сохраняется снимок показанной карточки. Обратная связь привязывается к этому снимку, поэтому последующее редактирование профиля не меняет смысл старой оценки.

## Локальный анализ

Разбор правил работает без модельного сервера. Для извлечения сведений из текста можно включить Ollama через `VACANCY_LLM_ENABLED` и `RESUME_LLM_ENABLED`. Модель и адрес сервера задаются в `.env`. Фоновая очередь сохраняет задания в БД и ограничивает параллельные обращения к модели. Параметры и команды запуска собраны в [примере конфигурации](../.env.example).

## Приватность

Рабочие профили, резюме и история принадлежат пользователю. Обучение по сохранённым событиям требует зарегистрированного согласия. Действие `learning-access --action erase` удаляет данные пользователя и отзывает затронутые материалы обучения. В таблице версий остаются служебные счётчики с числовым ID. По ним система отклоняет запоздавшие записи после удаления и повторной регистрации.

Диагностика приложения пишет события в stderr и локальные журналы. Контент резюме, токены, тексты переписки и ответы модели не предназначены для публикации.
