# Проверка подбора

Команды `benchmark-prepare`, `benchmark-label` и `benchmark-evaluate` готовят каталог, сохраняют оценки и сравнивают выдачу. Параметры доступны через `vacancy-analyzer --help`. Для оценки релевантности используйте независимо проверенные примеры и сохраняйте исходные выборки локально.
