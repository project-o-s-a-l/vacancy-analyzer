# Проверка качества подбора

Для сравнения вариантов ранжирования зафиксируйте профили, каталог, параметры отбора и принадлежность примеров к выборкам. Учебные примеры позволяют проверить механику отбора и формат отчёта. Для выводов о релевантности нужны независимые оценки вакансий.

```sh
vacancy-analyzer evaluation-prepare --output data/evaluation/sample
vacancy-analyzer evaluation-validate --bundle data/evaluation/sample
vacancy-analyzer evaluation-review --bundle data/evaluation/sample --output data/evaluation/review --reviewer reviewer-1
```

Последняя команда создаёт локальную форму и инструкцию. Реальные резюме, закрытые вакансии, таблицы оценок и файлы назначений храните в каталоге с ограниченным доступом. Для импорта предусмотрена команда `evaluation-import`. Разделение по людям и периодам сохраняется при сравнении, чтобы один профиль или повтор вакансии не учитывался как независимый пример.

В отчётах о качестве указывайте размер выборки, долю оценённых карточек, обязательные нарушения и интервалы неопределённости. Автоматическая разметка сохраняет своё происхождение. [Инструкция для рецензента](evaluation/REVIEW.md).
