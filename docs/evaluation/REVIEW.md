# Оценка вакансии для кандидата

Откройте `cards.html` в выданном каталоге. Для карточки подбора сравните сведения о кандидате с самой вакансией. Сначала проверьте обязательные условия, затем обязанности, опыт и навыки.

| Балл | Как выбрать |
| --- | --- |
| 0 | Есть явное противоречие обязательному условию или профессия не подходит |
| 1 | Совпадает часть требований, остаются существенные пробелы |
| 2 | Вакансия подходит, имеющихся сведений достаточно для рекомендации |
| 3 | Обязанности и условия особенно хорошо соответствуют профилю |

Запишите короткое основание со ссылкой на доступный фрагмент текста. Укажите неопределённость там, где кандидат или работодатель не сообщили важную деталь. Если вы получили карточку с одним источником, укажите проверяемые факты и выделите в тексте подтверждающие фрагменты. Заполните своё назначение самостоятельно. При расхождении независимых оценок решение фиксирует отдельный рецензент.

Сохраните результат формы и передайте его вместе с идентификатором назначения ответственному за оценку. Профили и ответы могут содержать персональные сведения и предназначены только для участников проверки.
